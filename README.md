
# Tetrafy

Tetrafy is a modern Tetris clone developed in C++, aiming to deliver a smooth and responsive gameplay experience. Designed with simplicity and performance in mind, Tetrafy offers a clean codebase suitable for learning purposes or further development.



## Features

- 🎮 Classic Tetris gameplay mechanics

- 🖥️ Built with C++ for high performance

- 🧩 Modular code structure for easy maintenance and expansion


## Download & Usage


### 1. Download the Latest Release:

- Visit the Tetrafy [Releases](https://github.com/Sound-Sloy/Tetrafy/releases) page.

- Download the latest .zip file (e.g., `Tetrafy.1.3.zip`).

### 2. Extract the Archive:

- Right-click the downloaded .zip file and select "Extract All...".

- Choose a destination folder and extract the contents.

### 3. Run the Game:

- Open the extracted folder.

- Double-click on `Tetrafy.exe` to launch the game.
    
## Build Locally

### 1. Clone the project

```bash
  git clone https://github.com/Sound-Sloy/Tetrafy
```

### 2. Go to the project directory

```bash
  cd Tetrafy
```

### 3. Open the solution file `Tetrafy.sln` with your preferred IDE (e.g., Visual Studio) and build the project.
